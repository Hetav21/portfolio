# Workflow Orchestration

- **Plan Mode Default**: Enter plan mode for ANY non-trivial task (3+ steps or architectural decisions).
- **Subagent Strategy**: Use subagents liberally to keep main context window clean. Offload research and parallel analysis.
- **Self-Improvement Loop**: Update lessons after ANY correction from the user.
- **Verification Before Done**: Never mark a task complete without proving it works. Run tests, check logs.
- **Demand Elegance**: For non-trivial changes, pause and ask "is there a more elegant way?".
- **Autonomous Bug Fixing**: Just fix bugs, don't ask for hand-holding.
