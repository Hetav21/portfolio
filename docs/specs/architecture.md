# Architecture

The project is a Bun Workspaces + Turborepo monorepo containing a Next.js Desktop Portfolio (`apps/web`) and a Next.js Blog (`apps/blog`) using MDX managed by Velite. The blog is integrated into the portfolio via an iframe. Both applications share visual consistency using Tailwind CSS and JetBrains Mono fonts. The blog is built to look like a standalone, readable website while adhering to the desktop environment's Rose Pine theme.
