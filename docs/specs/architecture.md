# Architecture

The project is a Bun Workspaces + Turborepo monorepo containing a Next.js Portfolio (`apps/web`), a Next.js Desktop Simulation (`apps/desktop`), and a Next.js Blog (`apps/blog`) using MDX managed by Velite. The blog is integrated into the desktop via an iframe. All applications share visual consistency using Tailwind CSS and JetBrains Mono fonts.
