When the user needs to analyze competitors or find content gaps for a blog post, use this skill.

## Purpose

Before drafting content, it is critical to know what is already ranking on Google. This agent analyzes the top 3-5 articles for a target keyword and generates a "Gap Report" to ensure the new draft covers angles the competitors missed.

## Execution Steps

1. **Search**: Run a web search for the target keyword or topic.
2. **Analyze Top Results**: Read the content or structure of the top 3 ranking articles.
3. **Identify Gaps**: Determine what these articles are missing (e.g., lack of technical depth, poor formatting, outdated information, missing use-cases).
4. **Generate Gap Report**: Output a structured Markdown report that highlights:
   - What the competitors did well.
   - What the competitors missed (The Gaps).
   - Specific angles and topics the `Ideation & SEO Specialist` should include in the brief to outrank them.
